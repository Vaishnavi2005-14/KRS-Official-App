## 📲 Installation Guide

Follow these steps to get the app up and running on your local machine:

### 1. ✅ Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (v3.0+)
- Dart (comes with Flutter)
- Android Studio or VS Code
- Git

### 2. 📥 Clone the Repository
```bash
git clone https://github.com/AgnivaMaiti/KRS-App.git
cd krs-app 
```
### 3. 📦 Install Dependencies
```bash
flutter pub get
```
### 4. 🧪 Run the App
```bash 
flutter run
```

### 🤝 Contribution Guide
We 💖 open source, and we want you to be a part of it! Follow the steps below to contribute:

1. 🍴 Fork the Repository
Click the Fork button in the top-right corner of this page.

2. 📥 Clone Your Fork
```bash
git clone https://github.com/<your-username>/krs-app.git
cd krs-app
```

3. 🪄 Create a New Branch
Always make your changes in a new branch.
```bash
git checkout -b feature/your-feature-name

```
4. 💻 Make Your Changes
Work your magic. Once you're done:
```bash
git add .
git commit -m "✨ Added [your feature or fix]"
```

5. 🚀 Push to Your Fork

```bash 
git push origin feature/your-feature-name
```
6. 📬 Open a Pull Request
Go to your forked repository

Click “Compare & pull request”

Ensure you're merging from feature/your-feature-name or page/your-page-name → main

Add a clear title and meaningful description.
